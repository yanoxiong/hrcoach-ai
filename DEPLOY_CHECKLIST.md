# HRCoach AI Launch Checklist

## Stage 1 — Local working app
- [ ] Install Node.js
- [ ] npm install
- [ ] Copy .env.example to .env
- [ ] Create a long JWT_SECRET
- [ ] Keep DEMO_MODE=true
- [ ] npm start
- [ ] Create a test business account
- [ ] Test all four manager tools
- [ ] Test employee add/delete
- [ ] Test saved history

## Stage 2 — Live AI
- [ ] Create OpenAI API key
- [ ] Add OPENAI_API_KEY to server environment only
- [ ] Set DEMO_MODE=false
- [ ] Test generated outputs with fictional scenarios
- [ ] Set spending/usage controls in your API account

## Stage 3 — Public web deployment
- [ ] Private Git repository
- [ ] Node hosting service
- [ ] Persistent database disk
- [ ] HTTPS
- [ ] Custom domain
- [ ] Production JWT secret
- [ ] Backups
- [ ] Error monitoring

## Stage 4 — Business readiness
- [ ] Final business name/trademark check
- [ ] Business entity decision
- [ ] EIN
- [ ] Business bank account
- [ ] Payment processor
- [ ] Privacy policy
- [ ] Terms of service
- [ ] Data retention/deletion policy
- [ ] Security review
- [ ] Incident response plan
- [ ] Professional legal/privacy review

## Stage 5 — Customer validation
- [ ] 5 test managers
- [ ] 10 test managers
- [ ] Record feature feedback
- [ ] Decide founding price
- [ ] Landing page
- [ ] First trial customer
- [ ] First paying customer
